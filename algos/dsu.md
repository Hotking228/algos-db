# DSU (Disjoint Set Union - Система непересекающихся множеств)

## Intuition
DSU (Disjoint Set Union) — это структура данных, которая эффективно объединяет множества и отвечает на вопрос "находятся ли два элемента в одном множестве?". Представьте себе группы людей в социальной сети: когда два человека знакомятся, их группы объединяются. DSU позволяет за почти константное время проверить, знакомы ли два человека (напрямую или через цепочку знакомых), и объединить их группы друзей.

## Approach
1. Изначально каждый элемент находится в своем собственном множестве (сам себе "родитель")
2. **Find(x)** — найти "представителя" (корень) множества, содержащего x:
    - Поднимаемся по ссылкам на родителей, пока не дойдем до корня (у которого родитель — он сам)
    - **Сжатие путей**: после нахождения корня переподвешиваем все пройденные вершины напрямую к корню
3. **Union(x, y)** — объединить множества, содержащие x и y:
    - Находим корни обоих элементов
    - Если они разные, делаем один корень родителем другого
    - **Объединение по рангу**: присоединяем меньшее дерево к большему

## Complexity
- Time complexity: **O(α(n))** — обратная функция Аккермана (практически константа, ≤ 5 для любых реальных n)
- Space complexity: **O(n)** для хранения родителей и рангов/размеров

## Code

### Базовая реализация
```java
public class DSU {
    private int[] parent;
    private int[] rank;
    
    public DSU(int n) {
        parent = new int[n];
        rank = new int[n];
        for (int i = 0; i < n; i++) {
            parent[i] = i;  // каждый элемент - корень своего множества
            rank[i] = 0;     // изначально все деревья имеют высоту 0
        }
    }
    
    // Находим корень элемента x (с сжатием путей)
    public int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]);  // сжатие путей
        }
        return parent[x];
    }
    
    // Объединяем множества, содержащие x и y
    public void union(int x, int y) {
        int rootX = find(x);
        int rootY = find(y);
        
        if (rootX == rootY) return;  // уже в одном множестве
        
        // Объединение по рангу: присоединяем меньшее дерево к большему
        if (rank[rootX] < rank[rootY]) {
            parent[rootX] = rootY;
        } else if (rank[rootX] > rank[rootY]) {
            parent[rootY] = rootX;
        } else {
            parent[rootY] = rootX;
            rank[rootX]++;
        }
    }
    
    // Проверяем, находятся ли x и y в одном множестве
    public boolean connected(int x, int y) {
        return find(x) == find(y);
    }
}
