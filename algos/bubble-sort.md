# Сортировка пузырьком

## Intuition
Сортировка пузырьком получила своё название из-за того, что большие элементы "всплывают" в конец массива подобно пузырькам воздуха в воде. Идея предельно проста: многократно проходим по массиву и меняем соседние элементы местами, если они стоят в неправильном порядке.

## Approach
1. Запускаем внешний цикл, который выполняется n-1 раз (где n - длина массива)
2. Во внутреннем цикле проходим от начала до (n-i-1) элемента
3. Сравниваем текущий элемент со следующим
4. Если текущий больше следующего - меняем их местами
5. После каждого прохода самый большой элемент оказывается в конце
6. Повторяем, пока весь массив не будет отсортирован

## Complexity
- Time complexity: $$O(n^2)$$ в худшем и среднем случае, $$O(n)$$ в лучшем случае (если массив уже отсортирован)

- Space complexity: $$O(1)$$ (сортировка на месте)

## Code
```java
public class BubbleSort {
    public void bubbleSort(int[] arr) {
        int n = arr.length;
        
        for (int i = 0; i < n - 1; i++) {
            boolean swapped = false;
            
            for (int j = 0; j < n - i - 1; j++) {
                if (arr[j] > arr[j + 1]) {
                    // Меняем местами
                    int temp = arr[j];
                    arr[j] = arr[j + 1];
                    arr[j + 1] = temp;
                    swapped = true;
                }
            }
            
            // Если не было обменов, массив уже отсортирован
            if (!swapped) break;
        }
    }
}
