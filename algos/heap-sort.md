# Пирамидальная сортировка (Heap Sort)

## Intuition
Пирамидальная сортировка использует структуру данных "куча" (heap) — двоичное дерево, где каждый родительский элемент больше (max-heap) или меньше (min-heap) своих детей. Идея заключается в том, чтобы сначала построить кучу из массива, а затем многократно извлекать максимальный элемент (корень кучи) и помещать его в конец массива, каждый раз восстанавливая свойство кучи.

## Approach
1. **Построение кучи (heapify)**: преобразуем массив в max-heap (каждый родитель больше детей)
2. **Сортировка**:
    - Меняем корень (максимальный элемент) с последним элементом кучи
    - Уменьшаем размер кучи на 1
    - Восстанавливаем свойство кучи для нового корня
    - Повторяем, пока куча не опустеет

## Complexity
- Time complexity: $$O(n \log n)$$ во всех случаях (лучший, средний, худший)

- Space complexity: $$O(1)$$ (сортировка на месте)

## Code

### Базовая реализация
```java
public class HeapSort {
    
    public void heapSort(int[] arr) {
        int n = arr.length;
        
        // Шаг 1: Построение max-heap
        for (int i = n / 2 - 1; i >= 0; i--) {
            heapify(arr, n, i);
        }
        
        // Шаг 2: Извлечение элементов из кучи
        for (int i = n - 1; i > 0; i--) {
            // Перемещаем текущий корень в конец
            swap(arr, 0, i);
            
            // Восстанавливаем кучу для уменьшенного массива
            heapify(arr, i, 0);
        }
    }
    
    // Процедура heapify для поддержания свойства кучи
    private void heapify(int[] arr, int n, int i) {
        int largest = i;       // корень
        int left = 2 * i + 1;  // левый потомок
        int right = 2 * i + 2; // правый потомок
        
        // Если левый потомок больше корня
        if (left < n && arr[left] > arr[largest]) {
            largest = left;
        }
        
        // Если правый потомок больше текущего наибольшего
        if (right < n && arr[right] > arr[largest]) {
            largest = right;
        }
        
        // Если наибольший не корень
        if (largest != i) {
            swap(arr, i, largest);
            
            // Рекурсивно применяем heapify к затронутому поддереву
            heapify(arr, n, largest);
        }
    }
    
    private void swap(int[] arr, int i, int j) {
        int temp = arr[i];
        arr[i] = arr[j];
        arr[j] = temp;
    }
}
