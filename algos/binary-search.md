# Бинарный поиск

## Intuition
Бинарный поиск основан на принципе "разделяй и властвуй". Если массив отсортирован, мы можем эффективно искать элемент, каждый раз отбрасывая половину массива. Представьте, что вы ищете слово в словаре - вы не будете просматривать каждую страницу, а откроете словарь примерно посередине то поймёте, в какой половине искать дальше. Далее процесс повторяется, то есть бин. поиск рекурсивен.
Несмотря на то что процесс по сути представляет собой рекурсию, удобнее применять итеративный подход, который еще и работает быстрее.

## Approach
  Существует 2 вида бин. поиска: левый и правый, различаются они по следующим параметрам:
  Левый: мы знаем что в заданном массиве слева лежат плохие объекты - не подходящие нам, с какого - то момента начинаются подходящие нам, картинка такая: ___/-----, в таком случае mid = (left + right) / 2
  Правый: мы знаем что в заданном массиве слева лежат хорошие объекты - не подходящие нам, с какого - то момента начинаются подходящие, картинка такая: -----\_____, в таком случае mid = (left + right + 1) / 2.
  Так же различны и методы смещающие границы, но структура одинакова:

## Complexity
- Time complexity: $$O(\log n)$$ - на каждой итерации массив уменьшается вдвое

- Space complexity: $$O(1)$$ для итеративной реализации, $$O(\log n)$$ для рекурсивной

## Code
```java
public class BinarySearch {
    // Левый бин поиск
    public int binarySearch(int[] arr, int target) {
        int left = 0;
        int right = arr.length - 1;
        
        while (left <= right) {
            int mid = left + (right - left) / 2; // предотвращает переполнение
            
            if (arr[mid] < target) {
              left = mid + 1;
            } else {
              right = mid;
            }
        }
        
        return left; // элемент не найден
    }

    // Правый бин поиск
    public int binarySearch(int[] arr, int target) {
        int left = 0;
        int right = arr.length - 1;
        
        while (left <= right) {
            int mid = left + (right - left + 1) / 2; // предотвращает переполнение
            
            if (arr[mid] > target) {
              right = mid - 1;
            } else {
              left = mid;
            }
        }
        
        return left; // элемент не найден
    }
}
```
